# Социальная сеть на Netlify

Небольшая русскоязычная социальная сеть с общей лентой, профилями, постами, изображениями и видео, реакциями, комментариями и уведомлениями. Исходная трёхвкладочная компоновка сохранена, а хранение данных перенесено с внешнего JSON-сервиса на управляемые сервисы Netlify.

## Технологии

- Статический HTML, CSS и JavaScript в `public/`
- Netlify Functions для серверного API
- Netlify Database (Postgres) и Drizzle ORM для профилей, постов, реакций, комментариев и уведомлений
- Netlify Blobs для аватаров, изображений и видео
- Чанковая загрузка файлов без преобразования в тяжёлые data URL

## Локальный запуск

1. Установите зависимости командой `npm install`.
2. Свяжите каталог с Netlify-проектом, если он ещё не связан.
3. Запустите `netlify dev --port 8889`.
4. Откройте адрес, который покажет Netlify CLI.

Схема базы находится в `db/schema.ts`. Миграции создаются командой `npm run db:generate -- --name <имя_изменения>` и сохраняются в `netlify/database/migrations/`.

## Ограничения

- Один файл или суммарный набор вложений поста ограничен 67 МБ на клиенте.
- Аватар ограничен 5 МБ.
- Лента возвращает последние 100 постов, чтобы сохранять быстрый интерфейс.
